# ROSSIUM Optimizer

**Optimiza y diagnostica tu PC con Windows para jugar y trabajar.** Revisa recomendaciones para tu equipo, decide qué cambios aplicar y compara mediciones reales antes y después.

[Comunidad y soporte en Discord](https://discord.gg/rossium)

## Qué hace

ROSSIUM Optimizer reúne en una sola aplicación herramientas para entender el estado del PC y ajustar Windows según el uso: juegos, juego competitivo, streaming, trabajo o portátil.

- **Asistente personalizado:** analiza el hardware y explica qué conviene revisar o ajustar.
- **Ajustes organizados:** opciones de rendimiento, energía, latencia, red, privacidad, servicios y personalización, con explicación y nivel de riesgo.
- **Perfiles de juego:** automatiza ciertos ajustes mientras juegas y permite restaurar el estado anterior al terminar.
- **Diagnóstico del PC:** ayuda a encontrar problemas de configuración, controladores, consumo de recursos, almacenamiento y conectividad.
- **Herramientas de mantenimiento:** administración de inicio y procesos, limpieza con confirmación y utilidades de Windows.
- **Historial:** permite revisar cambios aplicados y restaurarlos cuando la opción lo admite.

La versión revisada contiene un catálogo de **229 ajustes**. El contenido puede cambiar entre versiones.

## Mediciones y resultados

La aplicación muestra valores observados en el propio PC, como FPS medios, bajos del 1 % y 0,1 %, tiempo de fotograma, uso de recursos, ping, jitter y pérdida de paquetes. También permite comparar mediciones antes y después de un ajuste.

Esos resultados dependen del equipo, el juego, la escena, la resolución, los controladores y la conexión. **No se promete una mejora fija ni un aumento universal de FPS.** No se incluyen aquí cifras de pruebas comparativas: no hay un conjunto público de mediciones verificadas que permita afirmar resultados numéricos generales.

Algunos ajustes requieren permisos de administrador o reiniciar Windows, y ciertos cambios pueden afectar funciones del sistema. Revisa la explicación y el riesgo de cada opción antes de aplicarla.

## Lenguaje

La aplicación actual está desarrollada en **C#** para Windows.
